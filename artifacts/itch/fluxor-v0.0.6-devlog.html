Fluxor v0.0.6 - Archive Preview, Plugin Replace Flow, and Runtime Safety

This update focuses on plugin reliability, archive import clarity, and safer recovery when an external plugin breaks.

New

  • Archive Preview Window — importing a .fluxorprofile now opens a dedicated preview dialog before anything is added to the library
  • Plugin Replace Flow — when importing a DLL that matches an existing imported profile, Fluxor can replace it instead of creating a duplicate
  • Runtime Safety Actions — the diagnostics panel now includes actions to reveal plugin files and switch to a safe built-in profile

Improved

  • archive import now validates profile content and warns about missing files or ID conflicts before import
  • plugin updates preserve compatible parameter values when matching keys still exist in the new build
  • broken external plugins now surface clearer diagnostics for missing assemblies, invalid runtime metadata, and runtime failures
  • plugin reload and recovery workflow is more practical during testing and support

Archive Import Workflow

  • preview profile name, ID, runtime type, parameter count, icon presence, and bundled plugin DLL state
  • replace an existing profile with the same ID
  • import the same archive as a separate copy when you do not want to overwrite the existing profile

Diagnostics and Recovery

  • Reload refreshes the current plugin runtime
  • Reveal Files opens the plugin location in Explorer
  • Use Safe Profile switches back to a built-in fallback profile when an imported plugin is unstable or broken

Version Update

  • app version updated to v0.0.6
  • installer rebuilt for the current version

This release continues the 0.0.x polish phase and makes Fluxor safer and easier to use when working with external plugins and shared profiles.
