Fluxor v0.0.5 - Profile Archives, Save As, and Workflow Improvements

This update focuses on profile workflow, plugin usability, and overall editing comfort.

New

  • Save as Profile — create a separate profile from the current settings
  • Fluxor Profile Export — export a profile as a single .fluxorprofile package
  • Fluxor Profile Import — import a shared profile package directly into Fluxor
  • Plugin Diagnostics Reload — quickly reload the active external plugin runtime

Improved

  • cleaner import flow with a dedicated import menu
  • better profile management for built-in and imported effects
  • improved editing workflow for current profile actions
  • expanded localization coverage across editing and utility windows
  • better feedback during effect and profile operations with progress overlay states

Compatibility

  • new exports now use the cleaner .fluxorprofile format
  • legacy .fluxor-profile.zip archives are still supported on import
  • regular .zip profile archives are also still accepted

Why this update matters

Fluxor now behaves much more like a profile-based tool instead of only a live effect editor. It is easier to save your work, create variations, organize presets, and share complete profiles between systems or users.

Included in this version

  • Save as Profile window
  • single-file profile archive export and import
  • plugin diagnostics reload action
  • UI cleanup and localized labels in more editing surfaces

This release continues the v0.0.x polish phase and prepares Fluxor for the next rendering and workflow improvements.
