Fluxor v0.0.3 - Fixes and Stability Update

This version is focused on fixes, cleanup, and stability improvements.

Fixed

  • improved overlay topmost behavior so cursor effects are less likely to disappear behind other windows
  • reduced visible lag for cursor-following effects with the new global cursor attach control
  • cleaned up the built-in profile list to keep the default set smaller and clearer
  • updated the app header version display and release metadata for v0.0.3
  • rebuilt the installer package so the current setup matches the latest release state

Plugin and Workflow Improvements

  • continued cleanup of the DLL-only plugin workflow
  • kept the plugin workspace and sample projects aligned with the current release build

Notes

This update is mainly a maintenance release. It is intended to make the current version cleaner, more stable, and easier to use before further visual effect additions.
