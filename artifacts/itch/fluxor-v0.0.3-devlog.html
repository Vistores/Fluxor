Fluxor v0.0.3 is live

Fluxor v0.0.3 is now available.

This update focuses on stability, cursor-follow responsiveness, built-in profile cleanup, and improved plugin workflow.

Highlights

  • updated app version and installer package to v0.0.3
  • cleaner built-in profile set with clearer role separation
  • new cursor attach control to reduce visible lag on fast mouse movement
  • improved topmost overlay behavior so effects are less likely to fall behind other windows
  • continued DLL-only plugin workflow improvements

Built-in profiles

  • Minimal Suite
  • Neon Suite
  • Frost Halo
  • Matrix Cascade
  • Tap Cross
  • Critical Spike

Plugin workflow

Fluxor continues to support DLL-only plugins with editable metadata and settings exposed directly from code. The included plugin workspace and examples are intended to make custom effect authoring easier.

Installer

The installer package has been rebuilt for v0.0.3 and includes the current release build and bundled runtime installation flow.

Next steps

  • additional built-in effect polish
  • more plugin samples
  • more storefront and presentation cleanup

Thanks to everyone testing early versions and helping identify rendering and usability issues.
