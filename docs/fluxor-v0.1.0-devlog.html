Fluxor v0.1.0

Fluxor 0.1.0 is the first milestone-style release focused on stability, recovery, profile workflow, diagnostics clarity, and overall release polish.

Safe startup and recovery

  • Fluxor now starts in a safe built-in profile when the previously selected external plugin profile is missing or broken
  • a startup recovery banner explains what happened and keeps the app usable instead of failing silently
  • recovery flow now points directly to the plugin workspace for faster fixes

Profile workflow polish

  • duplicate an existing profile without rebuilding it from scratch
  • rename imported and saved profiles directly inside the app
  • edit profile descriptions without changing profile identity
  • keep built-in profiles protected while still allowing duplication

Diagnostics improvements

  • plugin diagnostics now provide clearer broken and error states
  • new Next steps guidance explains what to do when a DLL is missing, metadata is invalid, or runtime rendering fails
  • a dedicated diagnostics details window gives quick access to the technical state of the selected plugin
  • safe recovery actions remain available directly from the diagnostics panel

Localization and polish

  • startup warnings and tray interactions are now routed through localization instead of hardcoded text
  • profile editing and recovery workflows are integrated more cleanly into the main UI
  • plugin authoring documentation has been updated to match the current plugin API, including PluginRenderContext

Release direction

Version 0.1.0 is intended to mark the point where Fluxor feels like a more complete product: safer to launch, easier to recover, easier to organize, and easier to extend through plugins.
