Fluxor Plugin Authoring Guide
=============================

1. Core idea
------------
Fluxor uses a DLL-only plugin flow.

You build one plugin DLL.
The DLL contains:
- rendering logic
- plugin identity
- parameter schema for the UI
- default values and section grouping

Fluxor reads all of this directly from the plugin type.
Separate JSON manifests are not used anymore.


2. Where plugins live
---------------------

Installed Fluxor builds open this writable user workspace by default:
- `%USERPROFILE%\Documents\Fluxor\Plugins`

That folder is meant for:
- your own plugin projects
- sample plugin projects
- ready-to-import built DLL files
- the bundled `Fluxor.PluginSdk` folder

Fluxor copies imported plugin DLL files into its runtime catalog automatically.
The runtime catalog is separate from the user workspace.


3. SDK dependency
-----------------

Plugins compile against `CursorFX.Core.dll`.

In the repository, sample projects reference:
- `..\..\CursorFX.Core\CursorFX.Core.csproj`

In installed builds, sample projects fall back to:
- `..\Fluxor.PluginSdk\CursorFX.Core.dll`

That means users can build plugins without having the full Fluxor source tree.


4. What the plugin must implement
---------------------------------

Your plugin class must:
- implement `ICursorEffectPlugin`
- have a public parameterless constructor
- expose metadata and settings schema from code

Useful namespaces:

```csharp
using System;
using System.Collections.Generic;
using System.Windows;
using System.Windows.Media;
using CursorFX.Core.Interfaces;
using CursorFX.Core.Models;
```


5. Required runtime contract
----------------------------

Expose:
- `DisplayName`
- `PluginId`
- `Description`
- `IconGlyph`
- `AccentColor`
- `Kind`
- `Trigger`
- `GetParameters()`

Preferred modern implementation:
- `ApplyParameters(IReadOnlyDictionary<string, TemplateParameterValue> parameters, double masterOpacity)`
- `Update(PluginRenderContext context)`
- `Render(PluginRenderContext context, DrawingContext drawingContext)`
- `OnMouseMove(PluginRenderContext context, Point position)`
- `OnMouseClick(PluginRenderContext context, Point position)`
- `Dispose()`

Legacy compatibility still exists for:
- `Update(TimeSpan deltaTime)`
- `Render(DrawingContext drawingContext)`
- `OnMouseMove(Point position)`
- `OnMouseClick(Point position)`

But new plugins should prefer `PluginRenderContext`, because Fluxor now provides:
- `CursorPosition`
- `RawCursorPosition`
- `IsCursorVisible`
- `DeltaTime`
- `CursorSnapshot`
- `BackdropSample`


6. Minimal skeleton
-------------------

```csharp
using System;
using System.Collections.Generic;
using System.Windows;
using System.Windows.Media;
using CursorFX.Core.Interfaces;
using CursorFX.Core.Models;

namespace MyCompany.FluxorPlugins;

public sealed class MyPlugin : ICursorEffectPlugin
{
    private Point _cursorPosition;
    private double _size = 18;
    private double _opacity = 0.8;
    private Color _color = Colors.Cyan;

    public string DisplayName => "My Plugin";
    public string PluginId => "my-plugin";
    public string Description => "My custom effect.";
    public string IconGlyph => "M";
    public string AccentColor => "#4FD1C5";
    public TemplateEffectKind Kind => TemplateEffectKind.CursorAura;
    public TemplateTrigger Trigger => TemplateTrigger.FollowCursor;

    public IReadOnlyList<TemplateParameterDefinition> GetParameters() =>
    [
        new TemplateParameterDefinition
        {
            Key = "opacity",
            DisplayName = "Opacity",
            Section = PluginParameterSection.Shader,
            SectionName = "Shader",
            IsAdvanced = false,
            Type = TemplateParameterType.Number,
            Min = 0.05,
            Max = 1.0,
            Step = 0.01,
            DefaultNumber = 0.8
        }
    ];

    public void ApplyParameters(IReadOnlyDictionary<string, TemplateParameterValue> parameters, double masterOpacity)
    {
        if (parameters.TryGetValue("opacity", out var opacityValue) && opacityValue.NumberValue.HasValue)
        {
            _opacity = opacityValue.NumberValue.Value * masterOpacity;
        }
    }

    public void Update(PluginRenderContext context)
    {
        _cursorPosition = context.CursorPosition;
    }

    public void Render(PluginRenderContext context, DrawingContext drawingContext)
    {
        var brush = new SolidColorBrush(Color.FromArgb((byte)(_opacity * 255), _color.R, _color.G, _color.B));
        brush.Freeze();
        drawingContext.DrawEllipse(brush, null, _cursorPosition, _size, _size);
    }

    public void OnMouseMove(PluginRenderContext context, Point position)
    {
        _cursorPosition = context.CursorPosition;
    }

    public void OnMouseClick(PluginRenderContext context, Point position) { }
    public void Dispose() { }
}
```


7. How Fluxor builds the settings UI
------------------------------------

Fluxor uses `GetParameters()` to build the settings panel.

Each parameter should define:
- `Key`
- `DisplayName`
- `Section`
- `SectionName`
- `IsAdvanced` when you want the control to appear under the Advanced block
- `Type`
- `Min`
- `Max`
- `Step`
- one default value

Supported types:
- `Number`
- `Color`
- `Toggle`

Sections:
- `Trail`
- `Glow`
- `Ripple`
- `Shader`


8. Mapping rules
----------------

If your plugin reads keys like:
- `opacity`
- `primaryColor`
- `enabled`

then the same keys must exist in `GetParameters()`.

Keep keys stable after release.
Changing them later resets saved values for that plugin.
Use `IsAdvanced = true` for secondary or expert-only controls so the default UI stays clean.


9. Recommended structure
------------------------

Inside one plugin class, keep this order:
- metadata properties
- config fields
- runtime state
- cached visual resources
- `GetParameters()`
- `ApplyParameters(...)`
- `Update(...)`
- `Render(...)`
- `OnMouseMove(...)`
- `OnMouseClick(...)`
- `Dispose()`


10. Performance recommendations
-------------------------------

- clamp all numeric values
- use fixed-size buffers for trails and particles
- avoid per-frame file IO
- avoid reflection in update/render
- cache brushes, pens and parsed colors
- keep per-frame allocations low
- prefer one strong readable silhouette over many weak noisy particles
- keep screen sampling minimal if you use it


11. Visual recommendations
--------------------------

Good cursor effects usually follow one of these models:
- cursor is the source of an effect
- cursor leaves a short-lived residual effect
- cursor is wrapped by a contour, aura or shell

Examples:
- flame contour around the live cursor alpha
- void ribbon that slowly heals behind the cursor
- sparse fireflies with tiny curved micro-trails


12. How to create a new plugin
------------------------------

1. Open `%USERPROFILE%\Documents\Fluxor\Plugins`
2. Copy one of the sample folders
3. Rename the folder, `.csproj`, namespace and class
4. Update:
   - `DisplayName`
   - `PluginId`
   - `Description`
   - `IconGlyph`
   - parameters returned by `GetParameters()`
5. Build the project

Build command example:

```powershell
dotnet build .\Fluxor.PluginVelvetVoid\Fluxor.PluginVelvetVoid.csproj -m:1 -v minimal
```

Built DLL location example:

```text
Fluxor.PluginVelvetVoid\bin\Debug\net9.0-windows\Fluxor.PluginVelvetVoid.dll
```


13. Step-by-step example: create a simple cursor glow plugin
------------------------------------------------------------

1. Create a folder:
   - `Fluxor.PluginSoftDot`
2. Copy an existing sample `.csproj`
3. Rename the project file to:
   - `Fluxor.PluginSoftDot.csproj`
4. Create one class:
   - `SoftDotPlugin.cs`
5. Paste this starter code:

```csharp
using System;
using System.Collections.Generic;
using System.Windows;
using System.Windows.Media;
using CursorFX.Core.Interfaces;
using CursorFX.Core.Models;

namespace Fluxor.PluginSoftDot;

public sealed class SoftDotPlugin : ICursorEffectPlugin
{
    private Point _cursorPosition;
    private double _size = 16;
    private double _opacity = 0.7;
    private Color _color = Colors.White;

    public string DisplayName => "Soft Dot";
    public string PluginId => "soft-dot";
    public string Description => "A simple cursor-locked glow dot.";
    public string IconGlyph => "S";
    public string AccentColor => "#E2E8F0";
    public TemplateEffectKind Kind => TemplateEffectKind.CursorAura;
    public TemplateTrigger Trigger => TemplateTrigger.FollowCursor;

    public IReadOnlyList<TemplateParameterDefinition> GetParameters() =>
    [
        new TemplateParameterDefinition
        {
            Key = "size",
            DisplayName = "Size",
            Section = PluginParameterSection.Glow,
            SectionName = "Glow",
            Type = TemplateParameterType.Number,
            Min = 4,
            Max = 48,
            Step = 1,
            DefaultNumber = 16
        },
        new TemplateParameterDefinition
        {
            Key = "opacity",
            DisplayName = "Opacity",
            Section = PluginParameterSection.Glow,
            SectionName = "Glow",
            Type = TemplateParameterType.Number,
            Min = 0.05,
            Max = 1,
            Step = 0.01,
            DefaultNumber = 0.7
        },
        new TemplateParameterDefinition
        {
            Key = "color",
            DisplayName = "Color",
            Section = PluginParameterSection.Glow,
            SectionName = "Glow",
            Type = TemplateParameterType.Color,
            DefaultColor = "#F8FAFC"
        }
    ];

    public void ApplyParameters(IReadOnlyDictionary<string, TemplateParameterValue> parameters, double masterOpacity)
    {
        _size = parameters.TryGetValue("size", out var sizeValue) && sizeValue.NumberValue.HasValue ? sizeValue.NumberValue.Value : 16;
        _opacity = (parameters.TryGetValue("opacity", out var opacityValue) && opacityValue.NumberValue.HasValue ? opacityValue.NumberValue.Value : 0.7) * masterOpacity;
        _color = ParseColor(parameters.TryGetValue("color", out var colorValue) ? colorValue.ColorValue : "#F8FAFC");
    }

    public void Update(PluginRenderContext context)
    {
        _cursorPosition = context.CursorPosition;
    }

    public void Render(PluginRenderContext context, DrawingContext drawingContext)
    {
        var brush = new RadialGradientBrush(
            Color.FromArgb((byte)(_opacity * 255), _color.R, _color.G, _color.B),
            Color.FromArgb(0, _color.R, _color.G, _color.B));
        brush.Freeze();
        drawingContext.DrawEllipse(brush, null, _cursorPosition, _size, _size);
    }

    public void OnMouseMove(PluginRenderContext context, Point position)
    {
        _cursorPosition = context.CursorPosition;
    }

    public void OnMouseClick(PluginRenderContext context, Point position) { }

    public void Dispose() { }

    private static Color ParseColor(string? value)
    {
        try
        {
            return (Color)ColorConverter.ConvertFromString(value ?? "#F8FAFC");
        }
        catch
        {
            return Colors.White;
        }
    }
}
```

6. Build it:

```powershell
dotnet build .\Fluxor.PluginSoftDot\Fluxor.PluginSoftDot.csproj -m:1 -v minimal
```

7. Import the built DLL through `Import Plugin`
8. Tune `Size`, `Opacity`, and `Color` live inside Fluxor

This is the smallest practical example of the current plugin workflow.


14. How to import into Fluxor
-----------------------------

1. Open Fluxor
2. Click `Import Plugin`
3. The dialog opens in `%USERPROFILE%\Documents\Fluxor\Plugins`
4. Choose a built DLL
5. If the DLL contains several plugin types, choose one in `Plugin Type`
6. Optionally choose an icon for the plugin card
7. Confirm import

Fluxor will:
- read metadata from the DLL
- build the settings profile automatically
- copy the DLL and runtime companion files into its internal catalog


15. Testing checklist
---------------------

Before sharing a plugin, verify:
- the plugin appears in the profile list
- parameters are grouped correctly
- sliders and colors update live
- the effect survives rapid movement and repeated clicks
- the effect does not freeze when the cursor is hidden and shown again
- the plugin does not allocate excessively during long use


16. Common mistakes
-------------------

- missing public parameterless constructor
- not implementing `ICursorEffectPlugin`
- `GetParameters()` returns an empty list
- key mismatch between schema and code
- rebuilding heavy resources every frame
- implementing only legacy methods when the plugin really needs `CursorSnapshot` or `BackdropSample`
- making soft effects from too many noisy particles
- depending on another plugin DLL already being loaded


17. Maintainability advice
--------------------------

- keep one plugin project per folder
- keep one clear visual idea per plugin
- prefer 8 to 15 meaningful controls
- keep `PluginId` stable
- keep metadata close to the rendering logic
- treat DLL-only import as the canonical Fluxor plugin workflow
