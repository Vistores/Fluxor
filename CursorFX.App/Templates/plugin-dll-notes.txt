CursorFX external DLL plugin format

The plugin manifest stays JSON, but now it can point to a compiled DLL.

Root runtime fields:
- `RuntimeKind`
  - `0 = BuiltInTemplate`
  - `1 = ExternalAssembly`
- `AssemblyFileName`
- `EntryTypeName`

External plugin contract:
- The type referenced by `EntryTypeName` must implement `CursorFX.Core.Interfaces.ICursorEffectPlugin`
- It must have a public parameterless constructor
- The DLL should target `net9.0-windows`

How it works:
1. The DLL contains the rendering logic.
2. The JSON file contains the profile metadata and parameter list.
3. CursorFX reads the JSON, builds the UI from `Parameters`, loads the DLL, and passes the current parameter values into the plugin.

Parameter sections:
- Keep using the existing `Section` enum for coarse grouping.
- Use `SectionName` to show friendly custom group names in the UI, such as `Lightning Field`, `Impact Field`, `Trails`, or any other label.

Deployment:
1. Build the plugin DLL.
2. In CursorFX click `Import Assembly` and select the DLL.
3. Click `Import Plugin` and select the `.cursorfx-plugin.json` manifest.
4. Choose the imported profile in the plugin list.
